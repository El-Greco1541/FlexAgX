# Research roadmap — stages, not authorizations

| Stage | Objective | Status |
|---|---|---|
| CT-0 | Immutable original shader and traceable mapping | Implemented |
| CT-1 | Local modular API, validated ports, serial glue | Implemented and locally tested |
| CT-2 | Decompose CPU renderer P3–P8 into pass-specific intermediate contracts | Proposed |
| CT-3 | Differential tests, error tolerance policy, render-target precision decisions | Proposed |
| CT-4 | Separately startable service adapters with authenticated transport and bounded failure | Proposed |
| CT-5 | ReShade compiler/GPU conformance, incident and performance characterization | Proposed |
| Production | Requires explicit clearance; no present authorization | Locked |
